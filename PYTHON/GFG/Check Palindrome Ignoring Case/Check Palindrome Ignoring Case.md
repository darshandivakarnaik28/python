Given a string s consisting only of English alphabets, check whether it is a palindrome or not, ignoring the case of the letters. A string is a palindrome if it reads the same forward and backward when case differences are ignored.

Return true if s is a palindrome, otherwise return false.

Examples:

Input: s = "Hello"
Output: false
Explanation: Hello is not equal to olleH so it's not a palindrome.
Input: s = "TenEt"
Output: true
Explanation: TenEt == tEneT as we are ignoring the case.
Constraints:

1 ≤ s.size() ≤ 105
s consists only of English alphabets
