Given an integer n, print the hollow square pattern of size n using '*' character. 

Examples:

Input: n = 4
Output:
* * * *
*     *
*     *
* * * *
Explanation: It's a hollow square! Each side contains n = 4.
Input: n = 3
Output:
* * * 
*   *
* * *
Explanation: It's a hollow square! Each side contains n = 3.
Constraints:

1 ≤ n ≤ 10
