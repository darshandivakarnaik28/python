Given an array of integers arr[]. Use a for-each loop to print each integer in the array on a new line.

Examples:

Input: arr[] = [1, 2, 3, 4, 5]
Output:
1
2
3
4
5
Explanation: All integers of the array are printed on a new line using a for-each loop.
