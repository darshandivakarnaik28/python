You are tasked with designing a basic Vehicle Information System. As part of this system, you need to create a class named Car that represents a car with the following properties:

- brand (string): the brand name of the car
- model (string): the model name of the car
- year (int): the manufacturing year of the car

You need to implement the following :

Constructor to initialize these properties when a new object is created. 
A method named displayDetails() that prints all the details of the car in the following format:
Car Details:
Brand: <brand>
Model: <model>
Year: <year>
Examples:

Input: brand = "Ford", model = "Mustang", year = 1969
Output:
Car Details:
Brand: Ford
Model: Mustang
Year: 1969
Input: brand = "Toyota", model = "Camry", year = 2020
Output:
Car Details:
Brand: Toyota
Model: Camry
Year: 2020
