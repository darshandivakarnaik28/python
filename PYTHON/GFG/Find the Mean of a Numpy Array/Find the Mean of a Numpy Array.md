Given a 1-dimensional NumPy array arr of size n, find the mean of all elements present in the array.

Examples :
Input: arr = np.array([2, 4, 6, 8, 10])
Output: 6.0
Explanation: The mean of the elements in the array is:(2 + 4 + 6 + 8 + 10) / 5 = 6.0
Input: arr = np.array([1, 3, 5, 7])
Output: 4.0
Explanation: The mean of the elements in the array is: (1 + 3 + 5 + 7) / 4 = 4.0
