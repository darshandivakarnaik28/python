Even Positioned Characters in a String
Solved
Difficulty: BasicAccuracy: 61.13%Submissions: 170K+Points: 1Average Time: 10m
Given a string s, return a string containing all characters present at even indices (0, 2, 4, ...). The characters must appear in the same order as in the original string.

Examples:

Input: s = "Geeks"
Output: Ges
Explanation: The characters at even indices 0, 2 and 4 are G, e and s, respectively.
Input: s = "DoctorPhenomenal"
Output: DcoPeoea
Explanation: The characters at even indices are collected in their original order.
Constraints:

1 ≤ s.size() ≤ 105
s consists only of English alphabets
